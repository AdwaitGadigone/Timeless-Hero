# Timeless Hero

**Timeless Hero** is a 6-level time-travel platformer game built in Python using PyGame and Tkinter. This game was developed for the **2025 DPCDSB Board-Wide Game Development Competition**, where it proudly ranked in the Top 5 out of 200+ competitors, representing St. Edmund Campion!

## 🏆 Credits
Created by **Adwait and Aditya**.

## 📖 Storyline
Trapped in time, the hero needs your help to find a way back!
Advance through different eras, collect timers, and reach the time machines to progress. Each time machine will transport the hero to a new point in history. But be careful—time goons lurk across timelines trying to stop you. Help the hero get back to the future!

## 🚀 Features
*   **6 Unique Timelines (Levels)**: Travel through different eras with varying challenges.
*   **Dynamic Platforming Physics**: Features gravity, jumping mechanics, and collision detection.
*   **Collectibles & Score Tracking**: Collect timers across levels to track your score.
*   **Enemies & Obstacles**: Avoid time goons (blobs) and deadly lava pits.
*   **Story Dialogues**: Pre-game storyline dialogues built seamlessly with Tkinter.

## 🛠️ Prerequisites & Installation

To run this game locally, you will need Python installed on your computer along with a few required libraries.

1.  **Clone the repository** (or download the source code).
2.  **Install Python 3.x** if you haven't already.
3.  **Install Required Packages**:
    Open your terminal or command prompt and run the following command:
    ```bash
    pip install pygame pillow
    ```
    *(Note: `tkinter`, `pickle`, `os`, `sys`, and `time` are included in the standard Python library).*

## 🎮 How to Play

Run the main game script using Python:

```bash
python Timeless_Hero.py
```

### Controls
*   **Left Arrow (`←`)**: Move Left
*   **Right Arrow (`→`)**: Move Right
*   **Spacebar**: Jump

### Objective
*   Avoid the time goons and lava.
*   Collect the timers (coins) to boost your score.
*   Reach the **Time Machine** at the end of each level to progress to the next timeline.
*   Complete all 6 levels to win the game!
